# 🎯 Project Overview

> Every customer tells a story.

Some remain loyal.
Some silently leave.

The purpose of this project developed by **Neeraj Singh (DNAU)** is to discover **why customers churn**, **what patterns exist**, and **how businesses can prevent revenue loss** using Exploratory Data Analysis (EDA).

Instead of jumping directly into Machine Learning, this project focuses on understanding the data first—the most critical step in every Data Science pipeline.
